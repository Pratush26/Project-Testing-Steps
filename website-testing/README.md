# This is a quick proto-type testing example of testing a production grade website

1. Check images are used, properly related or not.

1. Check all links are working and redirecting the desired url
1. Maintain proper color consistancy by following color theme
1. Ensure responsiveness for all devices
1. Maintain proper space consistancy between sections
1. Check meta tag's info, canonical URL
1. Ensure all basic info are properly updated (logo, FavIcone, email, phone, email, address, social links)
1. Ensure all contents are relavent
1. Properly optimized the images
1. Properly varify authentication or authorization
1. Properly restrict api calls
1. Test all form submission
1. Add sitemap.xml, robots.txt
1. Add proper not found and error page
1. Ensure relavent toaster and alert messages
1. Improve the lighthouse test result
1. Ensure proper safety of env to avoid leak or other vulnerability
1. Check build and type errors
